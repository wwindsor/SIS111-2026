Desarrollar un programa modular que permita gestionar un inventario básico de materiales de laboratorio, aplicando estructuras de datos compuestas y funciones.
Consigna
Crear un programa en Python que permita administrar materiales de laboratorio de computación. Cada material debe registrarse con la siguiente información:

Código
Nombre
Categoría
Cantidad
Estado
Ejemplo:

Código: M001
Nombre: Teclado
Categoría: Periférico
Cantidad: 15
Estado: Disponible
El programa debe mostrar un menú con las siguientes opciones:

1. Registrar material
2. Listar materiales
3. Buscar material por código
4. Actualizar cantidad de un material
5. Mostrar materiales con baja cantidad
6. Mostrar resumen por categoría
7. Salir
Requisitos obligatorios
El estudiante debe usar:

1. Lista de diccionarios para almacenar los materiales.
2. Funciones para cada operación del menú.
3. Validación de datos.
4. Búsqueda por código.
5. Recorrido de listas con for.
6. Condicionales if / elif / else.
7. Ciclo while para mantener activo el menú.
Reglas del sistema
El código del material no debe repetirse.
La cantidad debe ser un número entero mayor o igual a 0.
Si un material tiene cantidad menor o igual a 3, debe considerarse como baja cantidad.
El resumen por categoría debe mostrar cuántos materiales existen por cada categoría.
